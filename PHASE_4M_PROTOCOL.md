# Phase 4M experiment protocol

Freeze this protocol and the case lists in `backend/research/holdem/phase_4m.py` before running the holdout. Phase 4L cases become calibration controls. The Phase 4K top-pair failure is a separate reproduction. New boards and profile streams are reserved for the holdout. No parameters are selected using calibration or holdout. Run calibration before opening the holdout. Use the same solver budgets, concrete menu, actual final-solve incoming reach and frozen later Hero policy across arms within each row. Report actual production mix separately from the controlled production response, conditioned response, observed pooled ablation and response oracle, whose root mixes all use 80 Phase 4L fixed-value updates. The oracle uses per-holding reference responses with estimated reach for selection. All arms are scored with the same reference posterior and continuation.

Use the four Phase 4K styles in the primary panel, with two independent 30-hand Coach profile streams, three starting depths (9, 15 and 30 bb), and eight new boards crossing checked-to and facing-bet decisions. Add a separate stress panel for the two aggressive families in which the reference can shove over a bet or raise when legal. The variants preserve the original pre-decision line and live profile, and have their own frozen response data. They shove with 2%, 10% and 35% probabilities by river rank class when small, half those rates when large, and otherwise follow the original fold/call rule conditional on declining to raise. After the shove use the frozen live Hero fold/call policy. The estimand is conditional EV on these finite reference panels. The response oracle receives no actual dealt opponent holding.

Generate response-training opportunities on six separate boards at all three depths, using the engine-replayed state and the concrete river tree menu. Draw 24 independent posterior holdings per first-reply opportunity and sample one reference action per draw using separate seeded streams. This is a controlled matched-data experiment with balanced menus and known reference styles. Only legal public opportunity context and observed action counts enter the model. Profile streams 0, 41, 51 and 52 supply the historical, calibration and holdout Coach histories respectively. The response model has separate observed count tables per style and stream. Each first reply is keyed by raise legality, effective price relative to pot before aggression after matching the outstanding call, fraction of effective stack at stake, and whether the wager was an opening bet or a raise. The price split is pot-sized inclusive and the stack split is half-inclusive on the high side. SPR and exact ratios are retained for analysis. No unsupported legal action is invented.

Use 20 prior observations at each context refinement from legal-only to price to price/stack/aggression. With no local support use the broader estimate, and with no same-legality observations use the production continuation. Pull the final target toward production with 32 pseudo-observations using the same legal-only support for conditioned and pooled arms. Fit the legal fold, call and aggressive groups to targets with existing iterative frequency fitting. Preserve the live within-group sizing mix, with a uniform split only for a holding with no live mass in the group. Adjust first replies only. Verify baseline payoff parity within 0.002 chips, plus independent Phase 4J parity for original fold/call references. Flag all nonfinite scores, unnormalized mixes, illegal actions and unexpected fallbacks as failures.

Primary promotion requires a mean gain of at least 0.10 bb at 15 bb and pooled, a positive lower bound of a 95% paired board-block bootstrap interval for pooled gain, nonnegative mean gain in every primary opponent and depth and in the raising stress panel, no row losing over 0.25 bb in either panel, and at most 10% of primary rows losing more than 0.01 bb. Require lower pooled marginal Brier and zero integrity failures. Also require median incremental single-decision candidate repricing time below 20 ms and peak traced incremental memory below 2 MiB on the holdout. A pass would only justify a separate integration and gameplay gate. Calculate Brier by integrating the known categorical outcome over the fixed estimated reach, reporting excess Brier and per-holding scores as well. Measure harm count at 1e-6 bb and practical harm at 0.01 bb, sum losses, and report action mix, supported regret, action-value MAE, and calibration by price, pressure, legality, style and depth. Report the paired conditioned-minus-pooled comparison separately. The historical correction is diagnostic and carries no gate weight. Bootstrap samples 8 boards with replacement, retaining all rows of each sampled board, with 10,000 seeded draws. This describes sensitivity to board composition with the tested styles and training seeds held fixed.
