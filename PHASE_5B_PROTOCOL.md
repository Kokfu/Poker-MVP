# Phase 5B — Frozen river shadow acceptance protocol

The Coach continues to select advice from its CFR mix. The observer prices the finite river tree after the incumbent action, explanation and API response have been computed. The protocol tests integration, accounting, privacy, output invariance and resource limits. EV improvement carries no acceptance requirement. Phase 4 and 5A results informed the scenarios and tolerances. Fresh results come exclusively from this protocol's new boards, profiles and exact controls.

## Boundary and contract

- Enable the offline observer with `POKER_COACH_RIVER_SHADOW=1`. Unset and `0` both disable it. The Coach's persistent range flag and Match's persistent range flag retain separate ownership.
- The immutable `RiverEvaluationInput` carries the public `DecisionState` and Hero cards, finite concrete action map, indexed frozen tree, actual full-precision root mix and sampled index, available CFR values, both working-set sizes and permitted public reply counts. It holds read-only float arrays for the Hero-compatible posterior, its projection onto actual CFR columns, holding-specific continuations and fixed river matchups. The projection uses the incumbent's current-node reaches. Nearest showdown rank with equal-rank averaging extends replies outside computed columns, following Phase 5A. The full posterior is the primary shadow estimate and the projected reading isolates the CFR traversal comparison.
- Version 1 JSON traces use a public-state digest, action menu and tree targets, projected and full estimates in net bb relative to folding, modal and seeded choices, conditional response summaries, concentration and working-set diagnostics, sensitivity repricing, runtime and status. Board and Hero cards are recorded locally. Estimated model EV, offline EV under the explicit reference law, and realized outcomes are separate quantities. The holdout scores counterfactual expectation and has no played outcome endpoint.
- The private default location is per-user Local AppData on Windows and `~/.local/state` on other hosts. `POKER_COACH_RIVER_SHADOW_DIR` can point to a private local research directory. Individual trace files inherit its access controls. POSIX creation uses owner-only directory and file modes. The observer performs no network or Coach database writes. The API returns the original advice and explanation. A missing incumbent solve, invalid geometry, ambiguous menu or tree over 128 nodes is recorded as unsupported. Deadline exhaustion records an incomplete result. Other observer errors are recorded by type. Failure to write a trace produces a content-free local warning.
- Cooperative deadline is the earlier of 150 ms from observer entry and 15 s from Coach service entry. It is checked during capture and between bounded traversals. File I/O, imports, operating system scheduling and an already-running primitive can extend elapsed time. Measure end-to-end wall time separately. Measure local compute separately from trace I/O.

## Measures and decision gates

- **Invariance.** Zero changed canonical Coach responses, full-precision probabilities, selected indices or CFR input fingerprints. Canonicalization removes timing fields. Focused regression separately checks unset versus explicit zero, RNG state, profile rebuilding, stored database bytes and stable Match plus Replay results under both persistent Match flag states. Require zero unexpected production fallbacks and zero shadow data in public responses. Inject capture, timeout, unsupported and trace-write errors and verify unchanged advice.
- **Accounting.** Require exact compatible-card outcome agreement with Treys, normalized legal probabilities, independent ledger agreement within `1e-10` bb, and CFR versus projected shadow error at most `1e-4` bb when the two price matching assumptions. Retain existing blocker, split-pot, short-call refund and reraise tests. Investigate larger residuals rather than labeling them approximations automatically.
- **Diagnostic coverage.** At least 95% of scheduled rows must complete under both hash seeds. Retain unsupported, timeouts, shadow errors and missing traces in the denominator. Require zero unexpected shadow errors. Require canonical equality across hash seeds, including decision ID, trace payload and status.
- **Disagreement.** Material pair gaps and harmful choices exceed 0.01 bb. Report CFR and shadow reference ranking accuracy, greedy disagreement and its conditional harmful-choice rates, false agreement, modal and seeded regret, and reference delta from a proposed shadow switch. Attribute differences using same-column residuals for arithmetic (G) or unexplained solver approximation (A), independent ledger discrepancies for payoff differences (B), reference range and reply substitutions for C and D, size/work-set projection and concrete-menu differences for E, and unsupported trees for F. Split out working-set projection from the action menu when reporting E. Classifications may overlap and a substitution is conditional on the same Hero policy.
- **Opponent-model visibility.** Report effective support, omitted mass and total variation to reference range. Compare reachable fold, call and shove reply marginals, defined as at least 5% path reach in both models. Count fold overestimate and call underestimate above 0.10 and absolute shove errors above 0.10. Score live sensitivity by relaxing 15% of the incoming range toward uniform compatible support, a documented stress for collapsed support, and applying the lower and upper continuation/aggression endpoints of the Phase 4Y public count model. Also combine range and reply perturbations. These are scenarios, without an assigned confidence level. Flag estimated sensitivity if the shadow preference's advantage over the incumbent moves by 2 bb, an alternate action outranks it by 2 bb in any scenario, or effective support is below 50. Compare precision and recall against reference regret of at least 2 bb, and compare to the disagreement-only flag. Treat shared streams as clusters. Give counts by style and separately for controls, without decision-level independence claims or promotion inference.
- **Runtime.** Run isolated holdouts and separate fresh-process CFR and shadow resource probes, with no concurrent full suites or heavy workloads. Probe rows 0, 5, 10, 15, 16 and 18 twice per arm with empty board cache and immediately warmed board cache. Report median, nearest-rank p95, max, peak process working set and per-trace compute plus end-to-end latency. All measured Coach calls must finish within 15 s. Require trace compute p95 within 150 ms, zero comparison-mode resource fallbacks, and incremental peak working set at most 64 MiB on these paired probes. A measured timeout stays in the denominator. Runtime differences include any board timing variation and instrumentation overhead on both arms.
- **Integration verdict.** Choose A when the correctness, invariance, coverage and resource gates pass. Choose B if the core accounting and invariance are safe and coverage or performance requires bounded repair. Choose C for a core correctness or strategy isolation defect. Any acceptance keeps the flag disabled by default.
