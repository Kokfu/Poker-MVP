# Phase 4Q — Frozen river wager likelihood experiment

## Scope and estimand

Change only the probability of the river opening wager already observed. Hold the captured incoming support and weights, concrete Hero menu, frozen future response rows, downstream Hero continuation and the existing 80-step fixed-value selector constant within each matched comparison. Replay live Coach separately for legality and unrounded payoff parity. This is an offline heads-up experiment. It does not model an observed river raise, a continuous bet-size density, or the effects of re-solving upstream. It does not authorize a production change.

Primary: the equally weighted paired difference in independent exact reference EV (candidate minus production, in bb) under production incoming reach and production responses. Score each mix under one exact posterior for the actual wager and the reference fold/call continuation. Regret is relative to the best action on the unchanged Hero menu.

## Wager and data design

The opening law is categorical over check, half-pot, pot and effective closure, using actual chip targets and existing size merges (85% of the effective cap). Unavailable size intent rolls into the closing class in the synthetic reference. A true bettor all-in exhausts that player's stack. A wager that consumes the defender's remaining stack also closes the action, including an overhang that would be refunded on coverage. Keep those two flags separate. A large bet with both players still able to raise is an ordinary bet; facing a closure, terminal fold/coverage have no reply branch. The equal-stack decision panel measures true bettor shoves. Unequal, short and overhanging controls are deterministic tests of closure semantics. Individual off-menu nonclosing targets are outside the estimand.

The frozen reference code defines the full check/size law by made-hand tier, plausible missed flush or suit blocker, SPR and turn pressure, with four independent tight/loose and aggressive/passive style definitions. Hero cards only remove impossible hypothetical holdings and determine payoffs; the opponent policy cannot read them. Priors use the Phase 4P causal public-history law before the river wager. For historical-only replays keep the original old wager law and earlier actions, so the reported case is exactly the one Phase 4P measured.

Fit a single count estimator. Eight production pseudo-observations anchor each combo. Add up to eight pooled tier observations, up to 24 matched population cell observations, and local opponent counts, projecting all mass onto legal actions before normalizing. A cell is effective SPR (at most 1, at most 2, above 2) crossed with any turn aggression. Tier × blocker defines six hand groups. Only revealed cards contribute hand labels. The scripted calibration protocol reveals a pair after check/half/pot/close with probabilities 0.75/0.50/0.40/0.25, independent of the actual holding conditional on public action; apply weight 0.25 divided by that known propensity. Historical conditional showdowns in ordinary Coach logs do not establish that assumption. This experiment measures transfer from a structured public data collection policy; passive real-world logs alone are not sufficient evidence of deployability. The training sampler generates independent rivers on the fixed opportunity grid rather than replaying the incoming range, and uses no holdout data. The inference module receives no style label, true range, actual Villain holding or oracle probabilities.

Population counts use 2,048 opportunities per synthetic style, seeds 74100000–74100003. Matched profile prefixes are 0, 3, 30 and 100 opportunities from seed 75100000 + 100 × stream + style index. Independent Coach profiles use the prior completed-history trainer and the corresponding prefix count. Development uses deal seed 437201, four boards and stream 121 (16 decisions). Holdout uses deal seed 437202, twelve boards crossed with all four styles and three streams (131, 132, 133) for 144 decisions. The deterministic schedule varies starting stack, earlier line, position, opening wager and training prefix by board and stream. Wagers are scripted and both betting sizes appear only where the production abstraction supports them. This is conditional EV on the selected decision strata. Expected calibration integrates over every legal hypothetical combo and all actions under the independently defined law; also record one independently sampled labeled event per row, with an RNG isolated from training. The historical cases are excluded from the gate.

## Diagnostics, inference and gates

In each setting compare baseline, candidate and wager oracle: A uses production incoming/production replies, B production/true, C true/production, D true/true. Cross-check exact terminal payoff against tree traversal; cross-check posterior using independent Bayesian and exact evaluators. Where the prior oracle extends into missing production columns, use compatible production reach-weighted action probabilities and the existing nearest-rank response extension. The full true-input oracle remains a diagnostic ceiling on the common menu. Report interactions, closing and normal wagers, strata by SPR, starting depth, history, style, profile size and stream, exact regret, modal changes and action shares. Report expected categorical log loss, Brier, category bias and weighted absolute error by size and made-hand tier. Log loss uses a floor of 1e−10. Strength tiers are proxies; they do not identify bluff intent.

Use 10,000 percentile crossed bootstrap resamples (seed 43703); resample board IDs and entire training streams independently, preserving all paired rows and four fixed styles at each board–stream intersection. This preserves repeated boards and profile prefixes shared within a stream. Three stream blocks limit inference about training variability; the fixed reference styles do not support inference to a population of players. Report stream-specific results alongside the interval.

Eligibility requires all of:

- Primary mean improvement at least +0.05 bb per decision and paired 95% lower bound strictly above zero.
- No primary loss greater than 0.50 bb and at most 10% with loss above 0.01 bb. Sum harm and count losses above 0.000001 bb for reporting.
- Each opponent mean at least −0.03 bb.
- Expected categorical log loss improves.
- Median incremental array calibration below 5 ms; maximum traced incremental allocation below 512 KiB on captured arrays. The incremental budget excludes offline training, hand rank/feature enumeration and replay; report process wall time and peak separately. Run each holdout with an external 1,200 s bound.
- Zero invalid probabilities, illegal menu recommendations, chip conservation failures, or unexpected solver fallbacks.

Freeze code, this protocol and reused inputs by SHA-256 before holdout; replay with Python hash seeds 13 and 31 and one BLAS thread. Compare all fields except timing and memory. Do not retune after the holdout. Clearing all gates could justify a separate gameplay validation proposal; otherwise reject progression and assess architecture before proposing another model.
